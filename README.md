
# ⚽ Website Sepak Bola

Website sederhana satu halaman yang membahas tentang dunia sepak bola. Website ini dibuat untuk memenuhi tugas praktik mata kuliah dengan menggunakan HTML, CSS, dan JavaScript.

## 📌 Deskripsi

Sepak bola merupakan salah satu olahraga paling populer di dunia. Olahraga ini bukan hanya tentang mencetak gol dan memenangkan pertandingan, tetapi juga mengajarkan kerja sama tim, strategi, kedisiplinan, dan sportivitas.

Website ini dibuat dengan tampilan sederhana, menggunakan kombinasi warna hijau dan putih yang terinspirasi dari lapangan sepak bola.

## ✨ Fitur Website

- Menampilkan nama mahasiswa.
- Memiliki heading tentang sepak bola.
- Menampilkan 3 paragraf informasi mengenai sepak bola.
- Menggunakan warna background dan teks.
- Memiliki tombol interaktif.
- Menggunakan JavaScript untuk mengubah teks ketika tombol diklik.
- Tampilan responsif untuk laptop dan smartphone.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| HTML | Membuat struktur halaman website |
| CSS | Mengatur tampilan dan desain website |
| JavaScript | Membuat interaksi pada tombol |

## 🚀 Cara Menjalankan Website

1. Download atau clone repository GitHub.
2. Buka folder project menggunakan Visual Studio Code.
3. Cari file `index.html`.
4. Jalankan file menggunakan browser atau Live Server.
5. Klik tombol **Klik di sini** untuk mencoba fitur JavaScript.
